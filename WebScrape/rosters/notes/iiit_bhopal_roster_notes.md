## Sources and endpoints
1. `https://iiitbhopal.ac.in/` is an Angular SPA (main.8df0c1d2213a03af.js). Faculty page data comes from JSON `https://iiitbhopal.ac.in/api/MasterData/GetAllFacultyDetail`: 38 records (Category Regular 10, Contract 22, Adjunct 6; fields Name, Post, Department, EmailId, Description html with bio/experience/links, SubmitDate). Also used: `/api/MasterData/GetDirectorDetails` (Director Ashutosh Kumar Singh), `/api/MasterData/GetSiteFront`, `GetDirectory`, `GetFilesData?DirectoryName=<dir>` (file listing of every upload folder).
2. Profile HTML pages uploaded under `/Document/ff/*.html` and `/Document/Faculty/*.html` (46 pages, URL from GetFilesData). 16 of them describe faculty who are NOT in the 38-record API list (2025-26 joiners, with iiitbhopal.ac.in email, "Assistant Professor ... till date, IIIT Bhopal"); they are included as `current`. Conflict log: all of them are on the institute server but absent from the API list; the API list is dated Nov 2024 to Mar 2025 in SubmitDate, the profile pages are newer.
3. Annual reports (live PDFs, `/Document/Important/`): 2018-19, 2019-20, Jan-Dec 2020, 2022-23, 2023-24 text-extracted with pdftotext; they list "Temporary Faculty", "Visiting Faculty" (MANIT/RGPV), adjunct faculty and regular faculty. 2024-25 report is an image-only PDF (pdftotext gives 128 bytes, no OCR tool on machine): NOT used. No 2016-17, 2017-18, 2020-21 or 2021-22 report exists on the site.
4. NIRF: I found no IIIT Bhopal NIRF data PDF on the institute site (GetFilesData has an empty NIRF folder; no NIRF link in any directory) and a web search found no nirfindia.org submission for it (a third-party page says the institute had not participated). nirfindia.org was not fetched. So there are NO NIRF tables for this institute; the NIRF 2018-2026 source named in the brief does not exist here.
5. Wayback CDX (`url=iiitbhopal.ac.in/*`, 506 URLs with status 200): no archived faculty-list page and no archived `GetAllFacultyDetail` response exist (only the 2019-08 home page, CMS JS controllers, notices, PDFs and API calls such as GetAllImportantData). The 2021 consolidated lists of eligible temporary-faculty candidates are candidate lists, not appointments, so not used. Hence no Wayback-based year-by-year faculty evidence; tenure years come from annual reports and profile pages only.
6. ORCID public API: one expanded-search `affiliation-org-name:"Indian Institute of Information Technology Bhopal"` (48 hits, mostly students with 0009- ids), then `/employments` for 7 name-matched people (6 accepted, 1 used only to adjudicate a conflict).
