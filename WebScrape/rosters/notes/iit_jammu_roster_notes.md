# IIT Jammu roster notes (iit_jammu)

Built 2026-10-28 by one agent. Scripts: scratchpad `work/iit_jammu_roster/code/` (nirf_rows.py, build.py, stage2.py, orcid_match.py, final.py, lst.py, arseq.py); data in `.../data/`. Reused from the golden-set agent: `iit_jammu_golden/data/fac_public.json` (website JSON), `wb_fac_2018.html`, and the annual-report text files `ar/ar*.txt`. All new fetches went through `polite_get.py`. No IRINS/Scopus/OpenAlex/Scholar scraping, no live ORCID call (0 API calls, no 429).

## Sources and endpoints
* Institute website (Angular SPA) JSON endpoint `https://userlogin.iitjammu.ac.in/api/faculty/public` (161 profiles; profile pages `https://www.iitjammu.ac.in/faculty/~<id>`). It lists current people only (151 regular/other plus 3 flagged Former Faculty, 2 INSPIRE/Ramanujan, 1 visiting, 1 advisor, 1 test profile "Abhishek Sharmata" in "Media Cell", excluded). Wins for "current".
* NIRF 2026 data submission `https://www.iitjammu.ac.in/pdf/institute/NIRF2026_IITJammu.pdf`: **image-only PDF, no OCR installed**. The 150-row "Faculty Details" table (pages 4-8: name, designation, join date, leaving date, currently-working flag, association type) was transcribed by eye from 130-dpi renders (`code/nirf_rows.py`, 150 rows verified against the serial numbers). Earlier-year files `NIRF2021..2025_IITJammu.pdf` do not exist (the site returns its HTML shell); the NIRF table is therefore a single snapshot (about Feb 2026). Rows with transcription doubts: none flagged, but dates were read visually.
* Wayback: CDX on `iitjammu.ac.in/faculty` gives only 12 captures 2016-2026. The old HTML site is archived for 2018-08-30, 2019-05-01 and 2019-10-17 (full lists of regular, visiting, deputation faculty); from 2021-12 onward the page is the Angular shell (empty). CDX for `/faculty-page/`, `/faculty-list`, `/people/faculty` returned 3 single-person captures and an empty shell. So 2020-2025 former faculty cannot be seen on archived lists.
* Annual reports (Google Drive PDFs, text files from the golden agent): FY2016-17 (lists 13 IIT Delhi "Faculty Support" mentors and 6 "In-charges"), FY2018-19 ("Faculty at IIT Jammu" by department), FY2020-21 to 2022-23 (per-department "Faculty Profiles" with research areas, plus visiting-professor bios in 2021-22), FY2023-24, FY2024-25 ("List of Faculty Joined in 2024-25"). FY2017-18 and FY2019-20 are image-only and were not used (gap).
* Offline ORCID index (employments only).
