## Sources and endpoints
1. Current site `https://iiitn.ac.in/` is a React SPA. The JS bundle (`/assets/index-BDIM6IFg.js`) calls a JSON API: `https://iiitn.ac.in/api/faculty/faculty_staff` (65 records, all `f_or_s=Faculty`, with name, positions, email, education, experience, research text; `join_year` field is NOT reliable: it is 2025 for ~35 people whose CVs say 2018-2024, so it was ignored). Profile URL column = `.../api/faculty/faculty_staff/<f_id>`. `https://iiitn.ac.in/api/media/media` lists all uploaded documents (876 rows): NIRF PDFs (5), annual reports (2016-17 .. 2024-25, English and Hindi), property-declaration lists by year (names of staff 2018-2025, only used as a cross-check), recruitment notices.
2. NIRF data PDFs (Engineering 2024 x3 variants incl. Overall/Innovation, Engineering 2025, Engineering 2026) from `/media/...pdf`, parsed with `pdftotext -raw` + `code/nirf.py`. They carry the faculty table with Currently-working flag, joining and leaving dates and association (Regular / Adhoc-Contractual / Other). Extraction: 2024 files 60 rows (57-58 working), 2025 77 rows (63 working), 2026 83 rows (70 working; last row = Director Prem Lal Patel in a Dean/Director category).
3. Annual reports: `.txt` available for 2019-20 E/H, 2020-21 E/H, 2022-23 E (partial), 2023-24 E/H, 2017-18 H; the English reports 2016-17, 2017-18, 2018-19, 2021-22, 2024-25 and Hindi 2016-17/2018-19/2021-22/2022-23/2024-25 are scanned images (pdftotext returns almost nothing; no OCR tool on this machine). Lists of "Regular Teaching Staff", "Faculty (On Contract)" and "Visiting Faculty from VNIT" in AR 2019-20, 2020-21 and 2023-24 were used.
4. Wayback (CDX `https://web.archive.org/cdx/search/cdx?url=iiitn.ac.in/*&output=json&from=2016&to=2025&filter=statuscode:200&collapse=urlkey`, plus per-URL month-collapsed queries; raw snapshots `.../web/<ts>id_/<url>`). Site generations: (a) 2016-2018 Joomla (`/index.php/...`; only Director/Deans/Registrar/Administration pages, NO faculty lists); (b) mid-2019 to 2020 PHP (`faculty.php?dep=bse|cse|ece`, `faculty-*.php`, `dept-*.php`); (c) 2020-2025 `page.php?name=faculty&id=192|204|183` / `/page/faculty/192|204/`, `/page/faculty-basic-science/183/` (cards with profile text); (d) from 2025 the React SPA (not archivable as HTML, so the API is the current source). I fetched 2020-10, 2021-10, 2022-06, 2022-12, 2023-09, 2024-07 snapshots of the three department pages (parser `code/cards.py`), the 2019-08 faculty pages, and the Director page for 2016-06, 2018-05 and 2018-08.
5. ORCID public API (see below). No IRINS/Scopus/OpenAlex/Google Scholar scraping.
* The fetch loop first returned 404 for all PDFs because my own list file had CRLF line endings (Windows). Re-run with CR stripped worked; the same CR bug briefly hit the ORCID employment loop. No data was affected.
